# ORBIT 2 soundtrack

Upload your music here as `Track_01.mp3` through `Track_10.mp3` (case sensitive), then rebuild or push to the release branch. Only present files enter the playlist; missing files never cause network requests. Restart the development server after adding files.

Tracks shuffle without consecutive repeats, with five-second fades and overlap. With no tracks, the game generates a quiet ambient chord. A single track plays once before returning to ambience, avoiding immediate repetition. Audio starts after a player gesture and the audio toggle mutes music and effects together. Use music you have permission to distribute.
